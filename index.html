An AI critic pipeline for short-form video

Problem
Short-form quality drifts when one person reviews their own work.
What I built
A production system: scripts checked against 60 written rules and a facts ledger, human-approved storyboards, Remotion renders from templates in 9 visual styles, ~28 automated checks per video (loudness, caption read time, frozen footage, safe zones), and independent critic agents that score script, retention and visuals. Every piece of feedback becomes a numbered lesson, then a rule or a check (44 so far).

Dragon Bound: a live Roblox game built with an AI agent loop

Problem
Shipping and maintaining a full public game (code, art, balance and security) without a team.
What I built
Claude Code edits the game's code in git, syncs it live into Roblox Studio, runs real playtests (scripted input, in-game measurements, screenshots), then commits and documents each change. Python and Blender MCP generate the art and upload it as private, group-owned assets. Every price, reward and XP amount comes from one economy formula, and telemetry tracks the onboarding, story and boss funnels.
